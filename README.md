# plp-da-a2-rainfall-advisory

* This project analyzes county-level rainfall distributions across Kenya using NumPy to clean data, compute annual metrics, and identify optimal agricultural planting windows.
* To run the analysis, open the Jupyter Notebook and execute all cells sequentially from top to bottom.
* Agricultural advisory findings highlight tailored two-month planting schedules per county, supported by rigorous data-cleaning imputations for incomplete field records.
